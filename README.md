# power-grid-ml/.github

The organization-level defaults of the **power-grid-ml** GitHub organization:

- `profile/README.md` — the organization profile shown on <https://github.com/power-grid-ml>.
- `CODE_OF_CONDUCT.md` — the code of conduct every repository of the organization inherits
  (Contributor Covenant 2.1) unless it ships its own.

Repositories inherit these community health files automatically; nothing here needs to be
copied into them.
